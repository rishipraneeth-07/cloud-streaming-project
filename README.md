
# Cloud-Native Batch and Streaming Data Pipeline

A containerized data engineering platform for batch processing, real-time
streaming, and automated storage tiering.

## Planned technologies

- Python and PySpark
- Apache Kafka
- MinIO object storage
- PostgreSQL metadata store
- Apache Airflow
- Prometheus and Grafana
- Docker Compose

## Core objectives

1. Process batch datasets using Apache Spark.
2. Process streaming events from Kafka.
3. Store processed datasets in object storage.
4. Automate HOT, WARM, and COLD storage tier transitions.
5. Convert and compress data where appropriate.
6. Track storage metadata and tiering operations.
7. Orchestrate jobs and monitor pipeline health.

## Project status

Initial repository setup. Implementation has not started.
